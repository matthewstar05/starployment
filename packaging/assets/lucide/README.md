# Lucide icons

These JobHub interface icons are from the official Lucide repository:
<https://github.com/lucide-icons/lucide/tree/main/icons>

Included icons: `layout-dashboard`, `briefcase-business`, `send`, `user-round`,
`settings`, `refresh-cw`, and `file-text`. The SVG artwork is bundled under the
Lucide Icons and Contributors ISC License in `LICENSE`. The license file also
contains the required MIT attribution for Feather-derived icons.

JobHub recolors `currentColor` in memory when creating Qt icons. The bundled
source SVGs remain the upstream artwork.
